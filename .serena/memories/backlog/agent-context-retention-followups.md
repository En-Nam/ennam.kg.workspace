These were intentionally deferred (spec §10). See `mem:decisions/daab-rbac-isolation-keystone-gate-verdict` and `mem:decisions/ecosystem-hermes-allocation`.

1. **Usage-based decay** — column `agent_context.last_recalled_at` ships (migration 000071) but is UNPOPULATED. Populate it on recall + switch decay from age-based (`updated_at`) to disuse-based. Avoids re-doing decay policy when recall noise persists.
2. **Un-archive / recovery + hard-delete TTL** — archival is currently a one-way trapdoor (nothing reads `is_archived=true`; embedding is dropped on archive and must be regenerated by the Python worker on un-archive). Add a recovery query and/or a TTL that hard-deletes long-archived rows. Document the trapdoor until then.
3. **Semantic (near-duplicate) dedup** — current dedup is exact (`md5(lower(btrim(content)))`). Add cosine-threshold dedup over the 384-dim embeddings (needs threshold tuning + embedding-pipeline coupling). Only if exact dedup proves insufficient on real corpus.
4. **audit_trail for the sweep** — sweep currently logs via slog only. Full `audit_trail` records need extending the `AuditOperation`/`AuditEntityType` CHECK enums (migration, pattern of 035) to add an archive op + `agent_context` entity type. CTO wanted this for a shared substrate; deferred as over-proportion for a janitor at v1.
5. **Capture-contract dedup ownership** — assert in writing: capture owns keyed dedup (`mem_key` unique index, in-place upsert); retention owns free-form (mem_key NULL) dedup only. Retention correctness is conditional on a complete capture path (gate-2 silent-amnesia, `mem:decisions/daab-hermes-keystone-verification`).
